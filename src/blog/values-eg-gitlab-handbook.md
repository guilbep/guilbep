# Values: e.g. GitLab handbook

_Stub seeded with research — references and current-state notes ready; prose still needs writing._

## TL;DR

A public values doc is only worth writing if it changes a decision you'd otherwise make — everything else is wallpaper with a Git history.

## Current state

- **The genre is narrower in 2026 than it looks.** GitLab is still the reference, **PostHog** is the most-evolved newcomer (100k+ word living doc), **37signals** the minimalist counter-model. Doist, Buffer, Oxide keep something public; most VC-funded scaleups quietly stopped.
- **Netflix's 2009 deck remains foundational but is now treated as a cautionary text.** "Stunning colleagues" and "keeper test" framings are critiqued for creating constant-audition anxiety and for being copied without the high-comp, high-severance context that made them tolerable. Netflix itself rewrote the memo; commentators called the update softer and less useful.
- **The distinguishing test**: is the doc edited regularly, version-controlled, and cited inside actual decisions (hiring rubrics, prioritisation, post-mortems)? GitLab/PostHog pass; most corporate value pages don't.
- **Recent shift (2024–2026)**: fewer sprawling new handbooks, more short "operating principles" docs. GitLab itself added a small principles layer on top; Stripe, Anthropic, and others lean on named principles rather than a wiki. **Handbook-as-recruiting-asset era is cooling; principles-as-decision-tool era is growing.**
- **AI-era pressure point**: handbooks are now also training data and prompt context for internal LLMs, which rewards crisp, decision-useful prose over aspirational paragraphs.

## Angle worth leaning into

**The one-week test.** If you can't point to a hire, fire, or prioritisation call **this week** where the doc actually broke a tie, it's marketing.

GitLab and PostHog pass because the doc *is* the argument; Netflix's current memo arguably fails its own original test.

- [GitLab Handbook — Values](https://handbook.gitlab.com/handbook/values/) — genre-defining public handbook; massive, opinionated, version-controlled. Recently added operating principles on top of CREDIT values.
- [37signals Employee Handbook (GitHub)](https://github.com/basecamp/handbook) — deliberately small, prose-heavy, transparent. Companions: ["How We Communicate"](https://37signals.com/how-we-communicate), ["How We Make Decisions"](https://37signals.com/how-we-make-decisions).
- [PostHog Handbook — Values](https://posthog.com/handbook/values) + [Culture](https://posthog.com/handbook/company/culture) — current standard-bearer for handbook-as-operating-system.
- Patty McCord, [The Netflix Culture Deck](https://pattymccord.com/the-netflix-culture-deck/) + [HBR — How Netflix Reinvented HR (2014)](https://hbr.org/2014/01/how-netflix-reinvented-hr) — the 2009 original; now widely critiqued.
- Patrick Collison on culture, [High Growth Handbook interview](https://growth.eladgil.com/book/chapter-5-organizational-structure-and-hypergrowth/you-cant-delegate-culture-an-interview-with-patrick-collison/) — Stripe's de-facto values doc.
